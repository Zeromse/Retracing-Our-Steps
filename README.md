# 雪山降临 1101 · 交互展示

完整原生 HTML、CSS、JavaScript，无依赖、无构建步骤。

## 运行

安装 Node.js 后，在本目录运行 `node server.cjs`，访问 http://127.0.0.1:4409 。也可以直接双击 dist/index.html；使用本地服务可获得更可靠的视频跳转体验。

## 文件

- dist/index.html：页面与可访问性结构
- dist/styles.css：响应式视觉与动效
- dist/app.js：关卡切换、筛选、原片播放、重建演示
- dist/assets：原片截图与压缩后的完整参考视频
- server.cjs：支持视频分段请求的本地预览服务器

## 内容边界

所有画面取自用户提供的视频，文本依据可见界面提炼。重建演示明确标注为简化机制，资源数值不代表真实游戏数据。素材权利属于原权利人。支持键盘操作、390px 手机与桌面布局，以及减少动态效果偏好。
